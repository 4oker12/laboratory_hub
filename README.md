# Laboratory Hub

Independent router laboratory and firmware-management-plane research workspace.

The project is intentionally separate from SIMNET Workbench. Device-specific router
targets live under `devices/`; the repository root provides the common launcher,
device registry, tests and CI.

The first target is Xiaomi Mi Router 4A Gigabit (R4A) Global/International firmware
3.0.24, migrated from the earlier RouterLab research branch.
