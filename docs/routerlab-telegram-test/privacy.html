RouterLab Cudy — политика конфиденциальности

Эта политика относится к тестовой версии 0.5 браузерного расширения RouterLab Cudy.

Расширение работает только со штатной локальной страницей роутера http://192.168.10.1. Оно читает HTTP-статусы, названия полей форм и признаки наличия авторизованной сессии, чтобы показать состояние первоначальной настройки роутера.

Содержимое веб-страниц обрабатывается локально в браузере. Расширение не собирает и не отправляет разработчику пароли, токены авторизации, cookie, историю браузера или данные о пользователе. Ни аналитика, ни рекламные сети, ни сервер разработчика не используются.

Расширение выполняет локальные запросы к самому роутеру. Отчёт остаётся в браузере и копируется только по действию пользователя. Персональные данные разработчиком не хранятся, третьим лицам не передаются. Удалить расширение можно через настройки Chrome.

Текущая версия не меняет настройки роутера. При будущем добавлении записи конфигурации назначение, доступ и эта политика должны быть пересмотрены до публикации обновления.
