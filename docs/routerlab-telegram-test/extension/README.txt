RouterLab Cudy Field Test 0.1
1. Download the ZIP branch archive from the RouterLab test page and unpack it.
2. Open chrome://extensions, enable Developer mode, click Load unpacked.
3. Select the folder docs/routerlab-telegram-test/extension.
4. Connect to Cudy Wi-Fi; navigate to http://192.168.10.1/cgi-bin/luci.
5. Press Проверить on the panel.
No WAN, server, external API, or configuration mutations. Diagnostic only.
