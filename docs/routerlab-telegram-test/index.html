Проверка сценария «получил ссылку в Telegram → подключился к Cudy → нажал кнопку». Никаких программ и серверов у абонента.

Подключение

  1. Подключитесь с ноутбука к заводскому Wi-Fi Cudy.
  2. Оставьте эту страницу открытой. Можно отключить интернет через телефон.
  3. Нажмите «Проверить роутер».

Cudy: 192.168.10.1 · WAN может быть отключён. Для открытия этой страницы из Telegram интернет нужен только один раз.

Результат

Ожидание проверки
После нажатия появится отчёт.

Тест выполняет только два GET-запроса к локальному роутеру. Пароли, токены, cookie, содержимое страниц и идентификаторы Wi-Fi не собираются и не отправляются.

Что проверяем

1. Local transport: позволяет ли браузер отправить запрос на 192.168.10.1 из этой HTTPS-страницы. Ответ opaque не доказывает, что роутер реально получил запрос.

2. CORS read: может ли страница прочитать ответ роутера. Без этого динамический заводской Bootstrap напрямую из внешнего сайта не работает.

Открытие страницы Cudy по кнопке — переход между сайтами, не автоматический запуск сценария. Этим тестом ничего на роутере не меняем.
