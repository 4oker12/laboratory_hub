RouterLab / Cudy / Test 0.1

Подключаем тестовое расширение

Один раз установить в Chrome, затем открыть Cudy. Расширение работает без интернета и показывает панель диагностики поверх штатной страницы.

Скачать архив с расширением

ZIP содержит экспериментальную ветку репозитория. Внутри нужна только папка docs/routerlab-telegram-test/extension.

  1. Распакуй скачанный ZIP на ноутбуке.
  2. В Chrome открой chrome://extensions, включи «Режим разработчика».
  3. Нажми «Загрузить распакованное расширение», выбери папку docs/routerlab-telegram-test/extension из архива.
  4. Подключись к Wi-Fi Cudy и открой 192.168.10.1.
  5. В правом углу появится RouterLab → нажми «Проверить».

Проверка только на чтение: страницы WAN/Wi-Fi и wifi.getstatus. Настройки не меняются. Chrome не поддерживает установку распакованного расширения по одному клику с произвольного сайта.
